E-Payment Listrik - Web-Based Electricity Payment System

A web-based electricity billing and payment management application built using Native PHP, MySQL, and Custom CSS. This system is designed to streamline administrative tasks for admins and provide customers with an easy way to check and process their monthly electricity bills online.

🚀 Key Features

Customer Dashboard: Allows users to view electricity consumption details, monthly bill amounts, and payment status instantly.
Transaction History: Tracks and displays detailed logs of all past payments made by the customer.
Admin Control Panel: Complete management system for customer data, meter readings input, tariff rate updates, and payment validation.
Invoice & Receipt Generation: Print-friendly layout for automatic receipt and invoice generation once payments are verified.
Multi-user Authentication: Secure and separate login systems for Admin/Staff and Customer accounts.

🛠️ Tech Stack

Backend: PHP (Native)
Database: MySQL / MariaDB
Frontend: Custom CSS3 (Pure CSS, lightweight, and responsive)
